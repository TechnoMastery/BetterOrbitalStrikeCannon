# How does this folder works ?
<p>Every .json file contained in the recipes/ folder and his sub-folders will try to load as a recipe.</p>
<p>
If the <bold>folder</bold> recipe/ is missing, it will be recreated and all default recipes will be pasted inside.
If you want no recipes, just empty the folder but <bold>keep the folder itself</bold> or the recipes will come back.
</p>
<p>
You can use the default recipe to understant how they work, or checkout the Recipe.java file and try to understand how
the checking is done. Warning, it goes crazy.
</p>
